🧾 Description of Our Project

✔️ Spring Boot + Spring Security Authentication
✔️ React Login and Registration with JWT
✔️ OTP Email Verification using JavaMailSender
✔️ Password Reset Functionality via Email
✔️ Protected Routes in React
✔️ Role-Based Access Control (Admin & User)
✔️ Modern UI with Bootstrap 5
✔️ API Integration (POST and GET requests)
✔️ Full-Stack Project Setup

🧑‍💻 Tech Stack Used

🧩 ReactJS — Frontend framework for building dynamic user interfaces
🧱 Spring Boot — Backend framework for RESTful API development
🔐 Spring Security — Authentication and authorization
📧 JavaMailSender — Email service for OTP and password reset
🎫 JWT (JSON Web Token) — Secure token-based authentication
🎨 Bootstrap 5 — Responsive UI design framework
🗄️ MySQL — Relational database management system

🔗 API Endpoints

🧾 /register — Create a new user account
✅ /verify-otp — Verify email using OTP
🔐 /login — Authenticate user and generate JWT
🔄 /reset-password — Send password reset link via email
🆕 /update-password — Update password after verification
